# Customer Shopping Behavior Analysis

## 📊 Project Overview

This project analyzes customer shopping behavior using a dataset containing **3,900 customer purchase records**. The objective is to uncover meaningful business insights related to customer demographics, purchasing patterns, subscription behavior, product performance, and revenue generation.

The project follows a complete data analytics workflow:

* Data Cleaning & Preprocessing using Python
* Feature Engineering
* Database Integration with PostgreSQL
* Business Analysis using SQL
* Interactive Dashboard Development in Power BI
* Business Recommendations based on findings

## 🛠️ Data Preprocessing

### 1. Missing Value Treatment

The dataset contained missing values in the **Review Rating** column.

Solution:

* Missing ratings were imputed using the **median rating of the corresponding product category**.

```python
df['Review Rating'] = df.groupby('Category')['Review Rating'] \
                        .transform(lambda x: x.fillna(x.median()))
```

### 2. Column Standardization

Column names were converted to lowercase and formatted using snake_case naming conventions.

Example:

```text
Purchase Amount (USD)
        ↓
purchase_amount
```

### 3. Feature Engineering

#### Age Group Creation

Customers were segmented into four age categories:

* Young Adult
* Adult
* Middle-aged
* Senior

#### Purchase Frequency Conversion

Text-based purchase frequencies were converted into numerical values (days).

Example:

| Frequency   | Days |
| ----------- | ---- |
| Weekly      | 7    |
| Fortnightly | 14   |
| Monthly     | 30   |
| Quarterly   | 90   |
| Annually    | 365  |

### 4. Redundant Feature Removal

The `promo_code_used` column was removed after evaluating its redundancy with the discount information.
